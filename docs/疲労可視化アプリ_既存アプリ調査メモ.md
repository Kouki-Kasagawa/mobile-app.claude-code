# 疲労可視化アプリ：既存アプリ調査メモ（2026-11-19）

スクリーンショット（別のAIとの会話）で挙がっていた10アプリと、判断ルール案をまとめたもの。
画像の文字は小さく、細かい説明は読み取りベース。**導入前に各アプリの公式ページで確認すること。**

## 1. アプリの分類（3カテゴリ・10アプリ）

### A. 自律神経・疲労度を「自動計測」するアプリ（客観指標の候補）

| アプリ | OS | 主な特徴 |
|---|---|---|
| ヒロミル | iOS / Android | カメラに指先を当てて計測。「疲労度」と「ストレス」の2軸でスコア化・グラフ表示 |
| Habitone | iOS / Android | カメラに顔を約60秒当てて自律神経バランスを計測。睡眠・体調と合わせてグラフ化、ケア提案 |
| カルテコ | iOS / Android | 顔を10秒前後撮影するだけで、自律神経バランスと疲労度をスコア化。色分けグラフで確認 |
| Upmind | iOS / Android | 指を30秒当てて自律神経を計測。結果に応じて約2分の癒しエクササイズを提案 |

### B. 「心の疲れ」「体の疲れ」を手動記録し、相関を分析するアプリ（主観指標の候補）

| アプリ | OS | 主な特徴 |
|---|---|---|
| Bearable | iOS / Android | 気分・エネルギー・症状・睡眠などを記録。カスタム項目（例：勉強時間）を追加でき、体調との相関関係を自動グラフ化 |
| Daylio | iOS / Android | 文字入力なしでアイコンをタップするだけで、気分・体調・やったこと（勉強や休憩など）を10秒で記録し折れ線グラフ化 |
| Cure | iOS のみ | 「身体的・精神的・感情的」「睡眠」など4つの観点で疲労度を記録し、疲れたときのストレス等の回復アクションを提案 |

### C. 「休む判断」や「学習との両立」をサポートするアプリ

| アプリ | OS | 主な特徴 |
|---|---|---|
| Focus on | iOS / Android | 日々の勉強度を5段階等で記録。疲れが一定ラインを超えると「そろそろ休みましょう！」と警告 |
| Routinery | iOS / Android | 学習や生活の習慣をタイマー付きで管理。連続記録が途切れないよう休憩モードも用意 |
| Studyplus | iOS / Android | 教材ごとの学習時間や進捗を記録・グラフ化できる学習管理プラットフォーム（他アプリとの併用向き） |

## 2. 目的別のおすすめ（元の会話の整理）

1. **「学習 × 疲労」の相関を見たい** → Bearable（勉強時間などをカスタム項目で追加）。手軽さ重視なら Daylio
2. **「やらなきゃ」と無理をしがちで、休むことに罪悪感がある** → Focus on（疲れが閾値を超えたら警告）、Routinery（連続記録のプレッシャーを避けた休憩モード）
3. **一番柔軟にやりたい** → Notion / スプレッドシートで自作ダッシュボード

## 3. 自作ダッシュボードの設計案（1日1回入力）

### 入力項目
日付 / 心の疲れ（0〜10） / 体の疲れ（0〜10） / 今日の学習時間・理解度 / 集中度（◎〇△）

### 判断ルール（信号方式）

| 信号 | 条件 | 行動 |
|---|---|---|
| 青信号 | 合計8点以下 | 通常どおり学習を進める |
| 黄信号 | 合計10〜13点、またはどちらかが6点以上 | 新しい内容は避け、復習や軽めの勉強だけにする（15〜30分程度） |
| 赤信号 | 合計14点以上 | 今日は学習を完全に切り上げて休む |

※閾値は目安。数週間記録して自分用に調整する想定。

### 運用の選択肢（元の会話で提示された3案）
- アプリ1つにまとめたい（Bearable等の自動化で統合）
- 学習管理と疲労計測アプリを分けて使いたい（組み合わせ方を知りたい）
- スプレッドシート/Notionで自作の判断表を作りたい（テンプレート項目がほしい）

## 4. 自分のアプリ設計との対応づけ（Claudeの整理）

この表は調査メモからの整理であり、確定事項ではない。

| 自分のアプリの要素（これまでの設計） | 既存アプリの対応 | 気づき |
|---|---|---|
| 主観的疲労（セッション前後の自己評価） | Bearable / Daylio / Cure の手動記録 | 既に成熟している。自前で作る価値は「記録」ではなく「客観との突き合わせ」にある |
| 客観的疲労（反応時間テスト等の認知課題） | A群はカメラによる自律神経計測（生理指標）で、認知課題ではない | 既存アプリと指標の種類が違う。ここが差別化の候補 |
| 主観×客観の2×2マトリクス（Stable / Tension / Distress / Eustress） | 見当たらない（B群は主観のみ、A群は客観のみ） | 「ズレの可視化」を両方持つアプリは今回の10本には無い。ただし網羅調査ではない |
| 疲労に応じた学習内容の調整（疲れていたら復習） | Focus on の警告、上記の信号ルール | 警告・信号ルールは既にある。「何をやるか」まで提案するかが論点 |

### 次に決めると進むこと
- 客観的疲労を「何で」取るか（アプリ内認知課題 / 既存アプリの自律神経スコアを取り込む / 取らない）
- 信号ルールの閾値を、固定値にするか個人ベースライン偏差にするか
- 最近の卒研テーマ変更（1対1ゼミの論証支援）と、このアプリの位置づけ
