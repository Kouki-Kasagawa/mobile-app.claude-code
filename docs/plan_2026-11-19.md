# 計画：学習記録アプリ（2026-11-19 時点）

- 目標：3月までに、自分の力で1円稼ぐ
- 使える時間：週5〜6時間（11月下旬〜3月で約85時間）
- 元にしたもの：`docs/調べたメモ：0円からWebアプリで稼ぐ.pdf`、`docs/competitor_research_2026-11-19.md`
- 方針：学習記録アプリに専念する（塾講師向けツールの案は `log/IDEAS.md` に保留）

## 誰の・何を・いくらで（1文）

> [部活、バイト、仕事をしながら勉強している忙しい学生・社会人]が、[疲れて学習をやめてしまうこと・続かないこと]を、[疲労を可視化したり、意図的な休みを設ける口実を作らせること]で学習が継続できるようになり、継続させるために、このアプリを使うことで、月300円払う。

**短い版（声を聞くとき用）**

> 部活・バイト・仕事をしながら勉強している人が、疲れて勉強が続かない問題を、疲れの見える化と「休んでいい理由」で解決し、続けるために月300円払う。

**位置づけ**
- 対象は「病気の管理」ではなく、「忙しい人が勉強を続けるための休み方」。慢性疾患のある人向けの海外アプリ（Visible・Bearable など）とは分かれる
- 「勉強の記録 × 疲労の見える化」の国内アプリは、下調べの範囲では見つからなかった
- 医療の表現は使わない（「医療目的ではありません」と明記する）

**確かめたいこと**
- 学生と社会人のどちらが月300円を払うか（学生向けの相場は「買い切り500円」が多め。社会人のほうがサブスクを受け入れやすい可能性）

## 公開の最低限（保留中・12月前半までに必要）

| # | 直すこと | 案 |
|---|---|---|
| A | 利用規約・プライバシーポリシーのリンク先が `example.com` | アプリ内に2ページ作り、下書きを書く。公開前に自分で読んで確認する |
| B | 疲労の判定が敏感すぎる（デバッグレポート #7） | ベースラインの初期値を OFF にし、「医療目的ではありません」を足す |
| C | ページのタイトルが空、`lang="en"` | `app/+html.tsx` で `lang="ja"` とタイトルを入れる（アプリ名を決める） |
| D | 「ログインして記録を同期」と書いてあるが、同期しない | 文言を直すか、公開版ではログインを隠す（どちらか決める） |

## SNS で反応を見るときのメモ

- 公開前でも、コンセプトや画面のスクリーンショットで聞ける
- 「いいね」の数より、「使ってみたい」「いくらなら払う」という返信を数える
- 投票で「学生／社会人」を分けて聞くと、どちらが払うかも分かる
